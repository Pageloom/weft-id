Group Claim

Sync group membership from this provider. With a claim name set, each sign-in creates missing groups as read-only IdP groups under the {{ connection.name }} group and matches the user's membership to the claim. Leave it empty to leave groups alone.

{% if connection.provider_type == 'github' %}

Enter groups to sync the user's GitHub organizations (as org) and teams (as org/team). With allowed organizations set, only those organizations and their teams are synced. Needs the read:org scope.

{% else %}

The claim in the ID token or userinfo response that lists the user's groups. Accepts a list of names, a list of objects, or a single name. Common values: groups (Okta, Entra, Keycloak), roles, or a namespaced claim such as https://example.com/groups.

{% endif %}

Only used when the claim is a list of objects, such as [{"id": "…", "name": "Engineering"}]. Defaults to name.

{% if connection.provider_type == 'entra' %}

Entra's groups claim carries directory object IDs, not names, so synced groups are named by GUID. Users in more groups than fit in the token (200) get no claim at all; WeftID records an oidc_group_claim_overage event and leaves their memberships unchanged.

{% endif %}

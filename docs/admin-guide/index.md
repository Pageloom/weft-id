# Admin Guide

The admin guide covers everything you need to manage your WeftID tenant, organized to match the
navigation bar: Directory, Identity Providers, Applications, Security, Audit, and Settings.

- [Directory](directory/index.md) — Users, groups, pending requests, the attribute catalog, and exports
- [Identity Providers](identity-providers/index.md) — Federate with external SAML and OIDC identity providers
- [Applications](applications/index.md) — Register downstream applications: SAML, OAuth2/OIDC, forward auth, and service accounts
- [Security](security/index.md) — Configure sessions, certificates, passwords, permissions, and authentication policy
- [Audit](audit/index.md) — Review event logs and activity tracking
- [Settings](branding/index.md) — Branding and tenant-wide display settings

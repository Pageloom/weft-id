# Directory

The Directory groups everything about the people in your tenant: the user list, groups,
pending approval requests, the profile attribute catalog, and data exports.

- [Users](../users/index.md) — Create, manage, and control user lifecycles
- [Groups](../groups/index.md) — Organize users into hierarchical groups
- **Requests** — Pending reactivation requests and forced profile-completion approvals. See
  [User Lifecycle](../users/user-lifecycle.md#reactivation) and
  [User attributes > Force profile completion](../security/user-attributes.md#force-profile-completion).
- [Attributes](../security/user-attributes.md) — Configure the standard profile attribute
  catalog and required fields (super admin only)
- **Exports** — Export a snapshot of users, group memberships, and application access. See
  [Audit > User export](../audit/index.md#user-export).

A blue badge on the **Requests** nav item shows the combined count of pending reactivation
requests and users flagged for forced profile completion.
